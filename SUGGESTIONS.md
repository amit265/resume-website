# Resume Website Suggestions

## High Impact Next Improvements

### 1. Add one detailed case study page
- Best candidate: `Question Games` or `Trivia Quest AI`
- Include:
  - problem statement
  - your role and ownership
  - architecture choices
  - Firebase or AI integration details
  - technical challenges and tradeoffs
  - outcome or launch result

Why: this will improve both recruiter confidence and search visibility better than adding more generic sections.

### 2. Add proof for shipped apps
- Add Play Store badges or links near the project cards
- Show 2 to 4 screenshots for your strongest apps
- Mention metrics already in your resume:
  - `240K+` combined active users
  - `177K+` flagship users
  - `54M+` tracked events

Why: your strongest differentiator is real product usage, so the website should prove it visually.

### 3. Create richer SEO pages over time
- Add separate routes for:
  - `/projects/question-games`
  - `/projects/trivia-quest-ai`
  - `/about`
- Give each page custom metadata and a focused keyword target

Why: a single homepage is good, but multiple focused pages give search engines more surface area.

### 4. Add structured data
- Add JSON-LD for:
  - `Person`
  - `WebSite`
  - `CreativeWork` or `SoftwareApplication` for key projects

Why: this can improve how search engines understand your site and profile.

### 5. Expand analytics after launch
- Track:
  - resume download clicks
  - project link clicks
  - LinkedIn clicks
  - GitHub clicks
  - Play Store outbound clicks

Why: this tells you what visitors actually care about, not just page views.
