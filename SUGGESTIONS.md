# Portfolio Improvement Plan (v2)

**Project:** Amit Kumar Portfolio (coderespite.in)  
**Framework:** Next.js 15 + React 19 + Tailwind CSS v4  
**Goal:** Transform the current portfolio into a world-class engineering portfolio that maximizes recruiter conversion while maintaining excellent SEO, performance, and accessibility.

---

# Overall Objective

The portfolio already demonstrates strong technical implementation and SEO.

The next iteration should focus on:

- Better storytelling
- More personality
- Stronger credibility
- Better recruiter conversion
- Premium visual polish
- Better case studies

The objective is to make visitors think:

> **"This developer builds products people actually use."**

rather than

> **"This developer knows React Native."**
